# SM100 (Blackwell) interface index

Demand-driven, exactly as `sm90/`: a recipe is written when a student is blocked
on that interface, follows `../TEMPLATE.md`, and is marked verified **only** on
one of the two evidence classes below. This file is not a plan; it is a ledger of
what has been earned.

Two classes earn a ✅, and nothing else does. **A GPU probe returning
`PROBE PASS`** is the default. The second exists because some knobs are
**numerically invisible** — descriptor moding, cache-policy bits, DEPBAR depth:
the bytes computed are identical either way, so no `max_diff` probe can see the
change, and under a probe-only rule this entire class could never enter the KB at
all. For those, **a shipped KEEP whose own NCU census shows the contract axis
moved** certifies, cited with the before/after axis readings and the gate window.
An entry carrying neither does not belong in this file.

## Interfaces

This directory is Blackwell's own tree. Two kinds of entry live here, and the
status column says which: **earned here** — certified by a GPU probe, or by a
shipped KEEP whose own census moved the contract axis — and **transcribed from
`sm90/`**, which carries a `Certification source` line naming the architecture its readings
were taken on.

What is deliberately NOT transcribed is the Hopper mechanism set: the WGMMA
trunk, the register arithmetic budgeted against a register file this
architecture does not have, and the recipes whose mechanism survives with
different parameters — the more dangerous kind, because they look transferable
and are wrong in the details. Those stay in `sm90/`. What does get transcribed
is the entries whose rule names no hardware unit at all: DSL algebra, probe and
census methodology, warp-level arithmetic. Re-earning those per architecture
buys nothing — a run once spent 13 minutes of its first turn rediscovering
`local_tile` tiler projection, written down since the Hopper work.

> **The read set is enforced**: a run reads and writes `hw_kb/cutedsl/<kb_arch>/` and
> nothing else (`loop.toml [loop] kb_arch`, default `sm90`; `hw_kb/cutedsl/README.md`).
> An sm100 run therefore never opens `../sm90/`; the links into it on these
> pages are for the human reader. A transcribed entry's own `Certification source` line, not
> the directory it sits in, is what says which architecture its readings came
> from.
